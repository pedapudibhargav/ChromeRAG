Getting started

The Widget CLI is distributed as a single binary for Linux, macOS and Windows. Download the archive for your platform, unpack it, and put the binary on your PATH.

Run widget init inside an empty folder to create a project skeleton. The command writes a widget.toml configuration file and a src directory with an example pipeline.

Use widget run to execute the pipeline locally. Logs are written to the .widget/logs folder and the exit code is non-zero when any stage fails.
