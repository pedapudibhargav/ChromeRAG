QA columns explained

Metrics are computed from HTML structure anchors — not from any single extractor — so ChromeRAG, Trafilatura, Readability, and others can be compared fairly.

Recall (content_recall)
Fraction of main-content text anchors (from main / article / content paragraphs) that still appear in the extractor output. Higher is better. Low recall means the tool dropped relevant chunks.
Noise ret (noise_retention)
Fraction of chrome anchors (nav / footer / header / cookie widgets) that still appear in the output. Lower is better. High noise retention means template junk will pollute embeddings.
Fbal (f_balanced)
A composite that rewards keeping content while removing chrome (harmonic-style balance of recall and 1 − noise_retention). Higher is better for overall RAG ingest quality. Related scores F_precision / F_coverage weight cleanliness or recall more heavily.
We also track token volume and keyword noise hits, but Recall / Noise ret / Fbal are the primary comparison axes against Trafilatura, Readability, markdownify, html2text, and BeautifulSoup.
