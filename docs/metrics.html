QA columns explained

Metrics use HTML structure anchors — not any single extractor — so ChromeRAG, Trafilatura, Readability, MarkItDown, and others can be compared fairly.

Recall (content_recall)
Fraction of main-content text anchors (from main / article / content paragraphs) that still appear in the extractor output. Higher is better.
Noise ret (noise_retention)
Fraction of chrome anchors (nav / footer / header / cookie widgets) kept. Lower is better for RAG vector hygiene.
Fbal (f_balanced)
Harmonic-style balance of high recall and low noise (1 − noise_retention). Higher is better for overall ingest quality.

Scoreable-page gate

Leaderboard means use pages where ChromeRAG content recall ≥ 0.05 (238 of 277 fetched). Thin pages are excluded from averages so empty shells are not silently mixed into SOTA claims. All baselines are scored on that same scoreable set. Details: Limitations.

Token volume is reported for context but is not the primary claim — MarkItDown can keep more tokens by retaining chrome.
