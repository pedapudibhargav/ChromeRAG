Quickstart

ChromeRAG extracts HTML files. Fetching and Playwright rendering belong to your crawler — if a page is a JS shell, render first, then extract (see Limitations).

Install

pip install chromerag          # Python 3.11+, CPU only
chromerag --version

From source (tests + benchmark baselines)

git clone https://github.com/pedapudibhargav/ChromeRAG.git
cd ChromeRAG
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,baselines]"
pytest -q

Extract one page

chromerag extract examples/site/pricing.html -o out/pricing.md --priority balanced --json-meta
# Thin / JS-shell HTML prints WARNING on stderr; --fail-on-thin exits 3
# chromerag extract spa.html -o out/spa.md --fail-on-thin

Site corpus: learn then extract

chromerag learn examples/site -o out/site_chrome.json --min-pages 3
chromerag batch examples/site -o out/batch --chrome-model out/site_chrome.json

Reproduce the public benchmark

python scripts/revalidate_corpus.py          # offline: recompute published means
python -m poc.run_corpus_comparison          # fetch corpus + score all tools (network)
python -m poc.export_site_results
Priority precision favors clean text. coverage favors keeping relevant text. balanced is the default.
