Quickstart

ChromeRAG extracts HTML files. Use your own crawler (or the POC fetch harness) to download pages.

Install

pip install -e .
# optional baselines for comparison
pip install -e ".[baselines,fetch]"

Extract one page

chromerag extract page.html -o out.md --priority balanced --json-meta

Site corpus: learn then extract

chromerag learn data/raw -o data/chrome_models/site.json --min-pages 3
chromerag batch data/raw -o data/outputs --chrome-model data/chrome_models/site.json

Compare on ~200 public URLs

python -m poc.run_corpus_comparison
python -m poc.export_site_results
Priority precision favors clean text (may drop chunks). coverage favors keeping relevant text (may keep more residual chrome). balanced is the default.
