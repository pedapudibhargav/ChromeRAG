Quickstart

ChromeRAG extracts HTML files. Fetching and Playwright rendering belong to your crawler — if a page is a JS shell, render first, then extract (see Limitations).

Install from GitHub

git clone https://github.com/pedapudibhargav/ChromeRAG.git
cd ChromeRAG
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
# optional: baselines for comparison
pip install -e ".[baselines,fetch]"

Extract one page

chromerag extract page.html -o out.md --priority balanced --json-meta
# Thin / JS-shell HTML prints WARNING on stderr
# chromerag extract spa.html -o out.md --fail-on-thin

Site corpus: learn then extract

chromerag learn data/raw -o data/chrome_models/site.json --min-pages 3
chromerag batch data/raw -o data/outputs --chrome-model data/chrome_models/site.json

Reproduce the public benchmark

python -m poc.run_corpus_comparison --no-fetch   # uses data/raw if present
python -m poc.export_site_results
python scripts/revalidate_corpus.py
Priority precision favors clean text. coverage favors keeping relevant text. balanced is the default.
