Ingest-time elimination of site template noise

ChromeRAG turns corporate HTML into RAG-ready Markdown: strip nav, footer, and CTA chrome, keep docs and pricing content, inject Schema.org front-matter, and optionally learn site-template patterns before extraction.

What it owns

HTML → Markdown

Pass HTML strings or files. Fetching, Playwright, and rate limits stay in your crawler.

Learn → extract

Optional STCE mines repeated chrome across a site, then strips it on every page.

Precision vs coverage

Choose cleaner vectors or higher content recall with a single priority flag.
