# GitHub Pages setup (one-time, after first push)

1. Push `main` (when ready) — do **not** push until tests/docs are ready.
2. Repo **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: **`gh-pages`** / folder **`/` (root)**
3. After the `pages` workflow succeeds, site is at:
   https://pedapudibhargav.github.io/ChromeRAG/
4. Pages: Home, Metrics, Results (corpus leaderboard), **Tests** (pytest report), Quickstart.
