# Security policy

ChromeRAG parses untrusted HTML. It does not execute scripts, fetch resources or write outside the
paths you give it. If you find an input that makes it hang, exhaust memory, or write unexpected
files, please report it privately through GitHub's "Report a vulnerability" button on the
repository's Security tab, or by e-mail to pedapudibhargav@gmail.com.
Supported version: the latest release.
